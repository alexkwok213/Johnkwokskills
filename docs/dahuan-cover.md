# 大欢公众号封面

从文章已经成立的钩子和结果提炼短文案，用 AI 生成公众号封面，让完整横版和同图中央方形都能看清标题与核心画面。

本例实际为 1922×818，约 2.35:1；中央方形保留完整标题和聊天到成果的画面关系。它是主题插画，不作为产品实测截图。

## 安装与使用

下载单包，将 `dahuan-cover` 放入助手技能目录，也可安装完整的大欢三技能套件。提供文章定稿、准确文案或参考图，例如：

> 使用 $dahuan-cover，为这篇文章生成封面，横版和中央方形都保留完整标题与核心画面。

> 使用 $dahuan-cover，检查这张封面的中文、缩略图和中央裁切，只修正发现的问题。

## 会交付什么

实际生成的原图、最终提示词，以及真实像素尺寸和裁切说明。默认目标为 2.35:1 横版并兼顾中央 1:1；输出尺寸以实际文件为准。需要独立方形文件时，再从同一张原图裁切。

先确定中央方形的完整画面，再扩展左右两侧。文字短、层级清晰，默认浅色背景与少量强调色；用户已有风格时按其要求处理。横版和方形都实际查看后，再报告本地检查结果。

## 使用条件

需要助手具备图像生成能力，优先使用内置 image_gen。仅安装技能不会提供生成工具或模型额度。整套 3:4 贴图和竖版首图由 `dahuan-image-post` 处理，可以共用视觉元素。

提示词与本次方法见[双裁切案例](../skills/dahuan-cover/references/dual-crop-example.md)。
