# 大欢公众号写作

把一个 AI 选题，从资料和案例整理成读者看得懂的公众号内容。完整稿默认交付长文与贴图两版，让同一份研究分别适合深入阅读和滑动浏览。

[下载三技能整包](../packages/dahuan-publishing-suite.zip) · [技能源码](../skills/dahuan-writer/SKILL.md) · [返回目录](../README.md)

## 适合什么任务

- 新产品、新功能发布后，解释适合谁、能做什么、怎样开始。
- 手头有实际操作记录，整理成输入、动作和结果清楚的教程或体验。
- 自己没有足够案例时，用已核实的官方或第三方实践讲清用途。
- 用相关案例解释一个工作方式或门槛的变化。

## 先安装，再提供材料

下载整包，将 `dahuan-writer`、`dahuan-cover`、`dahuan-image-post` 放入助手的技能目录。后两个是完整双版交付的配套技能。只下载写作单包时，也要为完整流程另行安装它们。

然后提供链接、视频、已有素材或实操记录，例如：

> 使用 $dahuan-writer，研究这个新功能，找几个有说服力的用途，面向初学者写成公众号长文和贴图两版。

> 使用 $dahuan-writer，把我的操作记录写成教程，保留真实输入、过程、投入和结果，不补写没有做过的事情。

> 使用 $dahuan-writer，检查这篇稿的标题和开头能否吸引目标读者，删掉没有增加价值的话，同步更新受影响的贴图。

## 从选题到成品

先研究命题、比较角度、选择能支撑主线的案例，再分别组织长文和逐页图解。资料只核验一次，关键事实与边界两版一致；有新的缺口时再补查。

长文提供正文、配图、公众号富文本复制预览和封面。贴图提供默认 3:4 的编号图片、整套预览、压缩包，以及标题与短正文。每次任务的材料、使用工具和完成状态以实际输出为准。

## 写出来应该是什么样

标题和开头尽早让读者看到价值；重点支持扫读。能用普通话讲清就不用黑话，确有必要的专业词就近解释。功能举例讲用途，事实、来源和亲历范围准确，资料核验记录留在后台。

方法可以随选题调整，不把所有文章固定成事件故事，也不要求每篇都凑一次个人实测。更多见[研究与选角度](../skills/dahuan-writer/references/topic-to-article.md)和[排版与发布检查](../skills/dahuan-writer/references/publication.md)。

## 使用条件

需要支持技能的 AI 助手，以及任务所需的联网、浏览器、图片生成或导出能力。技能本身不附带模型额度和外部服务权限。制作成品与上传发布是不同动作，按当前任务授权执行。
