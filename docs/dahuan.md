# 大欢创作套件

一套给 AI 助手使用的内容创作方法：从选题、研究、公众号文章、视频号口播，到成片、封面和贴图。统一入口 `dahuan` 判断这次要交付什么、读取项目已有进度，再交给对应技能；每个专用技能也可以直接调用。

[下载套件整包](../packages/dahuan-suite.zip) · [入口源码](../skills/dahuan/SKILL.md) · [返回目录](../README.md)

## 由哪些技能组成

| 技能 | 负责什么 | 介绍 |
|---|---|---|
| `dahuan` | 统一入口、共同原则、可接续的项目记录 | 本页 |
| `dahuan-writer` | 选题研究、公众号文章、视频号口播文案 | [介绍](dahuan-writer.md) |
| `dahuan-video` | 已确认口播做成竖屏成片：素材、解释动画、配音、配乐、字幕 | [介绍](dahuan-video.md) |
| `dahuan-cover` | 公众号 2.35:1 横版封面与中央方形裁切 | [介绍](dahuan-cover.md) |
| `dahuan-image-post` | 定稿改成 3:4 逐页贴图 | [介绍](dahuan-image-post.md) |

小红书改写和视频表演复刻是独立技能，按需另装。

## 设计上的几个选择

- **只做这次要的产物。** 只改一句口播，不会启动配音和成片；明确授权从材料做到成片时，按依赖顺序做完，不额外加审批环节。
- **能接着做。** 项目里保存给谁看、哪些事实已核实、哪版得到认可、做到哪一步、改过什么。换聊天、换模型或隔天继续，从下一步开始，不重跑全部流程。
- **成功方案可复用，但不当成硬规则。** 一次被认可的黑金商业案例做法保存为“制作方案”，保留具体版式、声音和节奏参数；换成冷静、失败或人物题材时可以换风格。
- **共同规则只写一份。** 事实口径、不编造亲历、真实截图与示意分开、各种“完成状态”的区别，放在 `dahuan/references/principles.md`，各技能引用。
- **一个模型就能用。** 不要求多 agent 或额外的评审系统；检查依靠实际看稿、看图、回看成片和试听。

## 安装

1. 下载整包，解压得到 `dahuan`、`dahuan-writer`、`dahuan-video`、`dahuan-cover`、`dahuan-image-post` 五个文件夹。
2. 放入你的 AI 助手的技能目录（例如 Codex 的 `~/.codex/skills/`，以实际配置为准）。
3. 新开一轮对话，提供素材，例如：

> 使用 $dahuan，这是一个 AI 商业案例的原视频和资料，先写视频号口播给我看；我确认后再做成片。

> 使用 $dahuan-video，口播已经定稿，用这些原片做成竖屏成片，风格沿用这个项目已认可的方案。

单独下载某个 `dahuan-*` 技能时，包里已附带它依赖的 `dahuan` 文件夹，两者要放在同一个技能目录下。

## 使用前需要什么

研究、网页查看、图像生成、配音和视频渲染，分别依赖助手实际具备的工具；技能本身不附带模型额度、TTS 或图像生成服务。成片渲染需要 Python、Playwright/Chromium 和 ffmpeg，详见 [渲染入口](../skills/dahuan-video/references/rendering.md)。上传、发布或改动外部账号，按当前任务的明确授权执行。
