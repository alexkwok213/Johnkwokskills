# 大欢公众号贴图

本技能独立负责 **公众号 3:4 贴图 / 图片消息** 的策划重组、HTML/CSS 卡片生成、真实像素导出、手机端可读性检查与短正文交付（与 `dahuan-article` 推文、`dahuan-video` 视频并列为三大平行载体技能）。

先读 [共同原则与红线](references/principles-and-red-lines.md)，再查同选题已有项目记录（[项目记录约定](references/project-records.md)）与核实素材；已有长文定稿直接沿用核心事实，不重复发起相同研究；只有局部调整时遵循 [增量制作与审批边界](references/incremental-production.md)。

## 职责范围与边界

- **本技能负责**：3:4（默认 `1080×1440`）滑动图解设计、竖版首图、HTML/CSS 多图渲染导出、图组预览与压缩包、贴图配套标题与短正文。
- **不越界**：写公众号长文推文或 2.35:1/1:1 横方封面交给 `dahuan-article`；写视频号口播或做 1080×1920 成片交给 `dahuan-video`。未经授权不自动上传或发布外部账号。

## 制作流程

1. **逐页定义读者收获**：不把长文整段缩小塞进卡片，先决定首图与每页各自交代什么结论、真实截图或步骤，按内容数量决定页数。
2. **保护真实界面与中文对比图**：产品界面、账单与后台操作优先使用真实高清截图或 HTML/CSS 排版生成的中文对比卡片，**禁止将含清晰文字或表格的原网页截图直接喂给 AI 生图模型重绘或拼合**。
3. **布局多样化与审美样张**：故事、人物、步骤、清单采用契合内容的布局，不强行每页塞入同构边框或教程步骤；新视觉方向先用最暴露风险的代表页自查，不把“文字没溢出”当成审美通过。
4. **导出真实像素核查**：详细参数、Chromium 导出踩坑（须 `fullPage: true` + `clip` + `scale: 'css'`）、手机宽度可读性与居中灰色图注要求见 [贴图制作与检查](references/production.md)。
5. **经验沉淀**：贴图常见排版与导出教训见 [贴图经验库](references/lessons.md)。

## 交付清单

- 按上传顺序编号的高清 PNG 或 JPEG 图组（核验每张实际像素尺寸）；
- 可点击放大查看原图的整套本地预览页，以及纯可上传图片压缩包；
- 简洁有反差的标题（优先 20 字内）、配套短正文，及保存在工作目录中的可编辑 HTML/CSS 源码；
- 如实报告仅完成本地像素与可读性检查，还是已实际保存至公众号草稿箱。
