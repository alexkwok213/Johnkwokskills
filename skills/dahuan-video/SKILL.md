# 大欢视频号创作与成片制作

本技能独立负责 **视频号全流程**：涵盖「选题讨论 → 口播脚本撰写/改稿 → 配音与原声切分 → 1080×1920 竖屏成片剪辑/渲染 → 混音质检 → 封面与项目归档」（与 `dahuan-article` 推文、`dahuan-image-post` 贴图并列为三大平行载体技能）。

先读 [共同原则与红线](references/principles-and-red-lines.md)，再查同选题已有 [项目记录](references/project-records.md) 与素材清单；只写口播就停在口播，只局部修改字幕或配乐就沿用已确认稿件与结构（边界见 [增量制作与审批边界](references/incremental-production.md)）。

## 第一阶段：口播选题与脚本写作

1. **动笔前四要素对齐**：写整篇新脚本前先读 [口播与叙事核心法则](references/spoken.md)，与用户对齐「主题内核、切入角度、情绪基调、主线与前 3 秒钩子」。
2. **站位与题材区分**：做普通人与从业者的「泥潭战友」，不做「居高讲师」；商业案例结合 [AI商业案例](references/ai-business-cases.md)、语言去 AI 味读 [大欢的声音](references/voice.md)、悬念推进见 [短视频叙事方法](references/he-laoshi-short-video.md)。
3. **文字先获认可再进制作**：所有新增或实质改写的口播文案需展示给用户明确认可后再进入配音和渲染（“继续制作”不自动批准未展示的新文案）。已经用户确认的台词直接进入制作，不重复询问。

## 第二阶段：竖屏成片制作与工程规范

1. **素材登记与真实画面优先**：登记原片来源、时长、画幅、用途与校验值。**严禁单张静态截图 `zoompan` 铺黑边充当动态视频**；按实际语音时间轴逐句配镜头，原片不足时不硬拿无关新闻画面循环凑时长，需补拍/生成画面应先明示为「示意画面」。
2. **声音先定节奏**：配音优先使用用户指定音色与模型；新音色先出短段试听确认表现后再整段生成。保留呼吸感与完整句尾（防截断缓冲），镜头间气口可统一约 120ms 起点；第三方采访原声严格按整句语音边界切分并保留必要水印来源（细节见 [采访原声与数字人](references/interview-and-avatar.md) 与 [剪映配音参考](references/jianying-tts.md)）。
3. **黄金三段式纯净视觉与渲染**：
   - 黑金商业案例起步参考 [原片＋MG 方案](references/recipes/original-footage-mg.md)：顶部双行大标题（视觉压舱石）＋ 中段纯净全屏主视觉（不叠多余中间观点卡片与碎片角标）＋ 中下段上提大字口播字幕（避开底部平台 UI 遮挡）。
   - HTML 逐帧渲染方案与 2 秒技术样片见 [可移植逐帧渲染](references/rendering.md)（已有剪映/HyperFrames 工程沿用各自工作流）。若同时装有专用包装工具也可配合使用。
4. **混音与质检**：读 [声音与质检](references/sound-and-checks.md)。可结合 `scripts/audit_video.py` 与 `scripts/voice_diag.py` 做响度（成片参考约 `-14` 至 `-16` LUFS、防削波）与静音诊断，但**数值检测与单元测试通过不等于听感或内容验收通过**，必须实际回看首帧、转场、字幕折行并手机外放试听。

## 封面、归档与交付边界

- **视频封面**：需要时可制作为 `1080×1440` 竖屏封面（核心信息兼容中央 `4:3` 横裁）；如果封面要作为视频首帧，须真实写入时间轴并同步校准音轨与字幕偏移。
- **导出才算资产**：剪映本地工程只是临时编辑态，须导出最终 `1080×1920` H.264 MP4 成片与发布文案/封面同版本归档进项目交付目录。
- **常见实战踩坑**：参见 [视频号经验库](references/lessons.md)。未经当前授权不自动上传或发布外部账号。
