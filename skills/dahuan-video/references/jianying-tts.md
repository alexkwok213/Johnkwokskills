# 剪映配音流程（computer use）

2026-10-22 的实测记录，当前版本需观察界面确认（剪映专业版 macOS，bundle `com.lemon.lvpro`）。

## 准备

1. 把定稿旁白按段写成 txt（一段一行），用 `scripts/make_tts_srt.py lines.txt jianying_voice.srt --slot 15` 生成字幕：第 k 段从 (k-1)×15 秒开始，每段时长 12 秒，段间留空。单段超过 12 秒时把 `--slot` 调大。
2. SRT 放在当前项目的 `04-视频工程/配音/`，剪映的文件对话框可以用 ⌘⇧G 直接输入路径。

## 操作剪映

1. computer use 申请访问「剪映专业版」。后台截图会缩放失真、界面几乎没有可点的辅助信息，按当前工具能力选择控制方式；会接管用户屏幕时先说明。
2. 首页「开始创作」新建项目 → 左上「文本」→「导入本地字幕」→ ⌘⇧G 输入 SRT 路径 → 导入。
3. 把「本地字幕」里的 SRT 拖到时间线最左端，N 段字幕按实际 slot 间隔排好。
4. 点一段字幕，⌘A 全选 → 右侧「朗读」→ 选音色（用户认可「解说小帅」）→ 点音色卡片上的调节图标，语速 1.15x → 「开始朗读」，出现“文本朗读完成”，每段字幕下生成一段音频。
5. 「导出」：改标题；关掉「视频导出」，勾选「音频导出」，格式 WAV；导出位置用文件夹按钮 + ⌘⇧G 选 `配音/`；导出，出现“音频导出完成”后关闭对话框，并释放 computer use。
6. 窗口位置可能在操作间移动，每一步先截图再点；剪映草稿会保留，用户想换音色时可直接在草稿里重新朗读、导出。

## 回到工程

`scripts/split_jianying.py 导出.wav --n 8 --slot 15 --out voice` → 得到 N1…N8.wav 与 durs.json。某个槽位找不到声音会直接报错，通常是字幕没对齐 0 秒或某段没生成。
