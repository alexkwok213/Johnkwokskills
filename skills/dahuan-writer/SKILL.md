# 大欢写作

先读 [大欢内容创作](../dahuan/SKILL.md)，查找同题已有稿件与相关复盘。理解读者最关心的事，选择最能讲清主题的角度和叙事方式；用户指定的声音、形式和修改范围优先。

围绕素材已有的人、行动和结果写自媒体文案，从中提炼读者关心的角度与自己的看法。正文直接讲事情，缺少的细节不写，不用交代资料缺口。

文章和口播分别考虑阅读或听觉体验：开头尽快让人知道为什么值得继续，节奏随内容变化，避免机械地按秒数、段数或固定模板填充。风格、修辞和参考作者按本题需要选用；避免空话、重复和生硬的 AI 腔，但不要把某种句式或标点一律视为禁用。给出自己的判断。

完成后通读全文，检查主线、读者理解和用户要求。用户只要局部修改时保留其余内容和已认可的风格。记录改动和交付状态。

按需查参考：商业案例读 [AI 商业案例](references/ai-business-cases.md)，口播读 [口播](references/spoken.md)，文章读 [文章](references/article.md)，修改和声音可查 [修改实例](references/revision-examples.md) 与 [声音](references/voice.md)。参考中的固定公式和历史案例用于启发，具体任务以用户指示和当前素材为准。需要封面、贴图或成片时分别使用对应的大欢技能。
