# 参照：半佛仙人

用于商业观察、吐槽两种风格，尤其是「学生 + AI + 大额营收」被质疑、骗局和灰色生意、行业潜规则这类题。2026-10-26 用户指定学习他的公众号和 B 站视频风格。

## 来源与可信度

- [虎嗅：半佛仙人 B 站涨粉分析](https://www.huxiu.com/article/338860.html)：选题、口语、表情包画面。
- [36氪：半佛仙人访谈](https://www.36kr.com/p/1774541811694083)：利益视角、风控出身、文字优先、主副号分工、自黑与人设、教人避坑。
- 以上都是第三方分析和他本人访谈里的自述，不是他的原作。**待原文校准**：请用户提供三到五篇公众号文章或 B 站视频，读完后逐条对照修改本文件（做法参照 [khazix-comparison.md](khazix-comparison.md)）。在那之前，下面的「学什么」按方向用，不当成他的硬规则。

## 学什么

| 手法 | 他怎么做（概括） | 大欢怎么用 |
|---|---|---|
| 先拆利益链 | 看一件事先问谁得了好处、谁吃了亏，讲背后的分账逻辑，不停在表面评论 | 案例里列出各方各得了什么：当事人、平台、媒体、客户、学校。观点落在利益结构上，不落在人品上 |
| 懂行的人看漏洞 | 风控出身，讲羊毛事件时不采访当事人，直接讲漏洞在哪、本该在哪里拦住 | 用具体细节拆解商业关系，让读者看懂各方的选择 |
| 教人避坑，不教人做事 | 他认为教人该做什么容易打脸，教人别踩什么坑更稳 | 结尾给一个观众下次就能用的检查动作，不给「你也能赚」的建议 |
| 专业翻成大白话 | 把面向企业的内容用普通人的话讲 | 接口、中转、开源这些词第一次出现时用一句白话解释，或直接换成观众能看见的东西 |
| 口语和自黑 | 把自己放低，拉近距离，也压低大众对他的道德期待 | 自黑只用真事，例如「上期我也是照着报道夸的」。不编经历，不为了好笑自贬 |
| 文字优先，画面服务文字 | 视频基本是念稿配表情包，画面粗糙但不妨碍理解 | 稿子先写好再配画面。可以在关键句后放自制表情包或数字人表情定格，作为原片和 MG 之外的第三种画面 |
| 不讨好但讨人喜欢 | 真诚，不回避问题，不把读者当傻子 | 不夸大，不卖关子到最后；该认错就认 |

## 适合的风格和选题

- 商业观察：借鉴他拆解利益关系和讲故事的方式。
- 吐槽：可以借他的口语和表情包节奏，但先过公平闸。
- 不适合：人物故事、亲测复刻。这两种要跟着主角或大欢自己的经历走，半佛的旁观拆解会抢戏。

## 不学什么

- 他的开场白、口头禅、身份设定和两个账号的人设分工。
- 他 B 站视频的长度。视频号仍按 [spoken.md](spoken.md) 的节奏，学口气和视角，不学十几分钟的篇幅。
- 他的「粗糙画面」。大欢已经有原片加 MG 的做法，表情包只是补充。
- 毒舌的程度。讽刺可以对着生意模式和利益结构，不对着具体的人下定性。

## 和大欢红线冲突处

| 冲突 | 处理 |
|---|---|
| 他常写有争议的事件 | 关注利益关系和具体行为，用大欢自己的语气表达判断 |
| 表情包铺底 | 用自制表情包或数字人表情，不用影视剧截图、明星照片和别人的作品 |
| 利益链分析容易推测动机 | 只写看得见的结果（报道播出后网站多了用户），不写看不见的意图（他就是为了获客） |
| 自黑 | 只用真实发生过的事，不编失败经历 |

## 写完怎么查

1. 有没有一段讲清「谁得了好处」，并解释各方的关系？
2. 有没有一个观众下次能自己用的避坑动作？
3. 每个专业词第一次出现时，普通人能不能听懂？
4. 自黑是不是真事？
5. 讽刺对着的是生意和结构，还是对着一个人下定性？后者要改。
6. 有没有学了他的口头禅或开场白？有就删。
