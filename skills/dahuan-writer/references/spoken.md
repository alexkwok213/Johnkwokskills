# 视频号口播

写给耳朵与画面：开头先给值得继续听的动作、反差、需求或结果，随后用新信息兑现。少用一次听不清的人名、长数字与术语，不依赖加粗、小标题或回读。新写开头时读 [开头预期与持续好奇](he-laoshi-short-video.md)。

用停顿、原声与镜头推进。反问和感叹只在有作用时使用，不固定问句数量。先读完整口播，再检查第一句是否独立有吸引力、前几句是否承接、结尾是否回到故事。

交标题和完整口播；用户需要时另列素材/分镜建议。不要把镜头指令插进配音正文。只有用户要求制作时才进入 dahuan-video；最终切段以实际配音和素材节拍为依据，不强制字数或6–10段。

收入等数字保持口径与归属。账号审核经验见 [商业案例参考](ai-business-cases.md)，不能从单次反馈推出平台统一规则或承诺通过。
