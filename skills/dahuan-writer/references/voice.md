# 大欢的声音

## 谁在说话

一个关注 AI 和普通人实际生活的自媒体创作者，在跟一个感兴趣但不了解的朋友讲一件事。他用自己的语言讲清故事，也敢说「我觉得」。

活人感先来自材料，再来自说话的位置，最后才是语气。口头禅、粗口和网络梗补不出活人感；一个具体的数字、一句当事人原话、一个真实发生过的动作可以。

## 怎么写

- 主语和动作先出来。「他拉了三十多个学弟学妹」好过「在团队组建方面，他……」。
- 一句一口气能说完，说不完就拆。长短句交替。
- 用具体的人、钱、时间、动作。「快了多少、省了几个人」好过「实现了效率提升」。
- 判断从正面说，依据放旁边。
- 批评前先承认对方做对了什么，或者观众会怎么替他反驳。
- 旁白是冷静讲案例、下判断的人，不是评书先生，也不用「说这话的，是……」这种卖关子的指代。
- 讲完就停。不总结全文，不硬升华。

## 写完后查一遍

这些写法一出现就像 AI。初稿写完再对着查，不要带着这张表去写。

| 写法 | 例子 | 改法 |
|---|---|---|
| 翻案腔 | 不是A，而是B；你以为……其实……；说到底 | 直接说 B，依据放旁边 |
| 三连问清单 | 先问三句：钱是谁付的？剩多少？能不能照着做？ | 换成从材料里得出的一个发现 |
| 三项以上同构排比 | 广东那个……浙江那个……开封那个…… | 留两项，第三项换一种进法 |
| 对仗口号 | 风口会过，差价会没 | 回到这个人、这件事的具体材料 |
| 提示性冒号 | 我们的看法是：…… | 直接说。冒号只用来引出原话 |
| 破折号 | —— | 逗号或句号 |
| 路标词 | 说白了、值得注意的是、这意味着、本质上 | 删掉，直接说内容 |
| 商业黑话、名词化 | 赋能、闭环、完成了对流程的优化 | 谁做了什么，钱和时间落在哪 |
| 自造金句太多 | 一篇里三处以上「」括起来的漂亮短语 | 留最有材料的一处 |

本机装了 human-writing 时，可以把稿子存成纯文本，运行 `human-writing 的文字检查脚本` 辅助检查。它查不出三连问、排比和对仗口号，这些靠人看。最后一步永远是读出声：纸面顺、嘴里拗的地方改掉。
