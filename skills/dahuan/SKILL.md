# 大欢创作入口

先确认这次要交付什么，再沿已有项目继续。一个模型可以按需使用全部技能，不要求多 agent 或额外评审系统。

## 从已有成果继续

先读当前项目说明、最新认可稿和用户的新要求。有已确认的信息就采用，只询问会实质改变作品的缺项。按 [项目记录](references/project-records.md) 保存必要状态；局部修改无需补齐整套文件。

## 只选本次需要的技能

| 用户要什么 | 交给谁 | 到哪里停止 |
|---|---|---|
| 选题、研究、公众号文章、口播文案 | [dahuan-writer](../dahuan-writer/SKILL.md) | 当前要求的文字交付 |
| 已确认口播做成片，或修改现有成片 | [dahuan-video](../dahuan-video/SKILL.md) | 成片与本次要求的配套文件 |
| 公众号横版封面 | [dahuan-cover](../dahuan-cover/SKILL.md) | 封面及双裁切检查 |
| 定稿改成逐页贴图 | [dahuan-image-post](../dahuan-image-post/SKILL.md) | 编号图片、预览与短正文 |
| 小红书表达或批量变体 | xiaohongshu-rewriter（可选安装） | 材料支持的笔记与实际数量 |
| 参考视频的动作/表演复刻提示词 | video-performance-clone（可选安装） | 分析与提示词，不自动生成视频 |

若任务同时包含多个产物，复用事实与已认可表达，按依赖顺序推进。未定稿先做文字；用户已授权从材料做到成片时完成全部必要步骤，不人为增加审批。仅要口播不能推出配音或视频授权。

选定技能后让它负责执行，不反复返回入口、不重新询问已确认的方向。缺可选技能时说明该环节缺项并完成可继续部分，不自动安装全部工具或调用付费服务。

## 共同判断

创作时读 [共同原则](references/principles.md)，只载入当前载体需要的参考。当前请求优先于个人偏好，个人偏好优先于示例方案；局部修改保留已认可的有效部分。项目结果优先于流程完整：检查真实稿件、图片和声画，不用步骤数量或自评得分证明作品优秀。
