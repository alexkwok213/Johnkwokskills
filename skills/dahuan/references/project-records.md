# 可接续的项目记录

遵守用户项目目录约定；没有约定时按选题建一个文件夹。已有等价文件就复用，不迁移、不重复建档。记录按工作实际产生，局部改稿只更新相关项。

| 记录 | 最少内容 |
|---|---|
| 项目说明.md | 给谁看、当前产物、范围、已有认可选择、下一步 |
| 素材与事实.md | 主张、来源/日期、素材路径和用途、原声时间段、已知限制；引用原片时记录时长与哈希 |
| 定稿.md | 当前标题与正文/口播、版本、认可来源；口播与镜头说明分开 |
| 制作记录.md | 采用的方案、实际音色/语速、素材和时间轴位置、输出路径、已做检查与未验证项 |
| 修改与复盘.md | 用户反馈、前后差异、修改原因、受影响产物、仍未解决的问题 |

不要从文件名“final”推断用户认可。可用“文字已认可；声音待试听；成片未验收”分别记录状态。换聊天或模型时先读项目说明和相关文件，从下一步继续，不重跑全部流程。

私有偏好可保存在项目说明或技能本地的 local-preferences.md；如已存在私人归档规则，遵循其实际授权和入口。公开套件不包含私人账号和原始媒体，升级前保留这些本地文件。跨项目复盘用于提供参考，不自动把某一期偏好提升为所有作品的硬规则。
