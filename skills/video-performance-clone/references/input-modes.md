# 首帧与全能参考

## 先确认再编排

模型与输入方式是两个选择。新的复刻任务没有明确模型时主动问 Seedance 2.5 / Seedance 2.0 / MiniMax H3；输入方式不明确时再合并问“仅首帧还是全能参考”。本次已经说清的项目不重复问。分析原视频可先进行，定稿等待缺失选择。

记录每份**将实际上传给生成工具**的素材：文件/编号、类型、负责保持什么、哪些内容不继承。用于分析的原片和工具里真正上传的生成素材要分开，不能自动把前者写成 `@视频1`。

| 用途 | 常用约束 | 不自动继承 |
|---|---|---|
| 首帧/开场图 | 起始姿态、人物身份、服装、场景、构图 | 后续僵持首帧姿态 |
| 产品图 | 形状、比例、包装、颜色、材质 | 产品图里其他人的脸、手或背景 |
| 动作视频 | 主动作顺序、重心、相互作用 | 参考演员身份或无关道具 |
| 镜头视频/分镜 | 景别、机位、运镜或真实切镜顺序 | 参考演员身份或无关剧情 |
| 声音 | 明确选定的音色、台词或环境层 | 未请求的背景音乐/其他人声 |

同一素材可承担多个职责，但冲突时必须知道谁优先。若用户尚未指定且会影响结果，合并问清；不要通过增加一堆参考图来碰运气。

## 仅首帧图

从实际首帧可见状态继续。若食物已拿在手上，直接进入后续进食，不能照搬原片从盘中取食的开场；若产品被遮住，不凭参考片补写不同包装。身份、场景和产品已在图中清楚出现时，不重复长篇重造静态细节。没有产品/运镜附加素材就不提图片2或视频1。

Seedance 指定上传图为首帧，用中文写后续第一、第二、第三阶段；H3用I2VA绑定及三字段，细节见模型适配文件。

## 全能参考（含首帧/开场图＋产品或镜头参考）

先绑定每份素材用途，再写动作。人物主要由目标首帧/人物图保持，产品由产品图保持，动作/运镜由指定视频保持；产品或动作参考中出现别人的脸不转移到目标人物。

Seedance 方舟 API 的 `first_frame/last_frame` 模式与 `reference_image/video/audio` 全模态模式互斥。选择全模态模式时，可以文字指定某张参考图用于开场，但其首帧匹配不等同于严格首帧参数锁定。不要在同一请求中拼接互斥role；写提示词时也不要承诺两者兼得。来源：[官方API说明](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。

H3的首帧走I2VA/FL2VA家族，全参考走Ref2VA。Ref2VA可定义具体画面锚点，但仍需所用入口支持该任务；模板不能创造界面里没有的功能。来源：[MiniMax官方模型说明](https://www.minimax.io/news/minimax-h3-open-source)。

## 问询示例

“这次用 Seedance 2.5、Seedance 2.0 还是 MiniMax H3？参考方式是仅首帧图，还是全能参考？如果是全能参考，请说明各素材分别要保持人物、产品还是镜头。”

这是文字澄清示例，不要求用户重复上传已提供文件。可用异步问询工具时边等回答边分析；没有选择时不默认沿用上一模型。
