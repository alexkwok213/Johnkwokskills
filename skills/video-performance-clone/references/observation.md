# 观察与声画对齐

先看全片，确定关系、空间、镜头和情绪推进，再看局部连续帧。一个举手至少分准备、抬起、指向/停住、回落。嘴角上扬可能是讥讽、苦笑或情绪失控；先写可见变化，再作有上下文的解释。

区分主动动作与自然形成的姿态。物体因长度、重力或抓握自然横置时，描述结果即可；不要扩写成额外的摆正、调整或展示动作，除非连续画面明确支持。用户对动作意图的澄清要同步到生成提示词和样本记录。

观察眼睛开合/凝视方向、眉间张力、脸颊、嘴唇、下颌、头角度。眨眼、闭眼强调、低头避视是不同事件。画面左/右与身体左/右分开。不可见的动作不补全。

证据层级：单帧=姿势；低频连续帧=粗变化；8–12fps=轨迹；逐帧或连续播放=准确接触、切点、眨眼和口型。模糊或遮挡仍要保留时间范围。

声音先检查音轨，优先已有本地多语 ASR。没有音频理解工具时可输出 ASR 候选和能量测量，但音色、气声、咬牙、嘲讽、无配乐均须标未听辨。

ASR 保存原结果，校对版注明改字依据。第一次不喂用户原台词，避免偏置；第二次可对照但不拿原台词当答案。说话人依据嘴型、镜头及声音；重叠声不强行分配。

环境已有 MLX Audio 可用：

```bash
<有mlx_audio的python> -m mlx_audio.stt.generate --model '<本地模型或已配置repo>' --audio '/绝对路径/audio.wav' --output-path '/绝对路径/transcript' --format json --language zh --gen-kwargs '{"word_timestamps":true}'
```

或者 mlx-whisper `transcribe(..., language='zh', task='transcribe', word_timestamps=True)`。先检查依赖与权重，模型目录存在不等于可加载。不默认下载大型权重。

RMS 只表示相对能量，混有声音、碰撞、距离和混音影响，不证明重音/情绪/音色。台词字数除以时长只能叫粗略口语速度。描述语气与前一句的变化，避免捏造分贝、基频或情绪百分比。

镜头区分剪辑、运镜、演员运动、焦点变化。切到更近景别不等于推镜。机位微晃需要连续证据；不能由几帧推断抖动频率。

质感可观察：光线方向、窗户关系、亮暗、背景虚化、肤色、纹理、颗粒、雾感、运动模糊。相机、胶片、光圈、真实时间、补光或磨皮操作无法唯一反推。

置信度高=直接可见/听见/测量；中=连续证据支持但遮挡/粗采样；低=语义推测/ASR疑义。每项附原因，不用一个总体评分遮盖声音缺项。
