# 观察转导演指令

交付时把以下内容合并成一条直接可用的生成提示词。先确认本次模型和首帧/全能参考方式，再用对应适配。优先在对话中给完整代码块，保存同内容的 `prompt.txt`；脚本、表格、分析与来源另放报告。生成正文里没有ASR标签、置信度、待听辨、平台未知等分析说明；缺乏证据的细节省略，不补造台词。

全局层：参考素材职责、画幅、角色/场景、座位/视线、光影/质感、声音原则。时长主要放生成设置或正文外说明，动作段落默认不标秒。只给首帧时继承图中可见细节，主要写后续变化。用户指定 ARRI、F1.4、50mm、下午五点可保留为创作参数，不宣称从原片测得。

先后顺序用第一阶段/第二阶段或首先/接着/最后；实际换机位或切镜才增加镜头编号。一个镜头内三个动作仍是一个镜头。用户明确需要同步切点时再添加模型适配的时间信息，不能把“支持时间戳”解释成“必须写时间戳”。

每镜强调“触发词＋具体改变＋回落”，如说到“我一个人”才抬前臂、提高声音，指向对方后立即回落。不要在一秒内同时要求眨眼、咬牙、流泪、握拳、拍桌、摇头。

## 让写实表演进入生成正文

情绪要在画面里发生。对推动剧情的转折，从“触发→神情/视线变化→身体行动→收住或对方反应”中选择能说明因果的细节，写进最终提示词；不要求每拍集齐全部要素。例如心虚可写成“听见要查手机，目光迅速落到手机，身体先僵住，随后抢着伸手”，说谎可写成“避开对方视线，解释时起句急、后半句结巴，手收回后僵在身前”。这些是导演写法示例，具体表演须依据本片或标明的创作建议，不冒充测量事实。

- **说话者与听者**：说话有重音、语速或停顿的变化；不说话的角色仍以注视、迟疑、避视或重心变化接收信息，不等轮到台词才开始表演。选择与剧情有关的反应即可。
- **动作的重量**：关键动作写清准备、发力、接触及后续惯性。搀扶涉及承重与失衡，拍落涉及爪/手接触后物体受力离开，倒地涉及躯干下沉与身体落点；毛发、衣料与饰品随身体略滞后。避免身体匀速漂移、关节瞬移、道具自行运动。
- **自然的脸与节奏**：眼睑、视线、嘴部和头部随理解、情绪及说话协调，眨眼不机械等间隔，也不长时间僵直睁眼；听者不做对方台词口型。不要规定每次眨眼、每个角度或所有停顿。
- **与对象匹配的质感**：继承首帧的实际光线、明暗与纹理；人保留自然皮肤细节，动物使用眼睑、耳位、口鼻与重心等适合其结构的表现，保留毛发层次、接触阴影和运动模糊。不把人的眉毛、毛孔、泪痕硬套到动物，也不把某样本的机型、下午暖光或浅景深套到所有新片。

生成正文只锁定决定原片效果的动作顺序、关键接触、对白转折、镜头和连续性。细微表情、眨眼、视线、头部/手腕姿态和动作内部停顿默认允许自然变化；可将重复的进食等过程合并成一个较宽时间段。报告可以详细观察，提示词不必强制重演所有微动作；用户明确要求逐项复刻时再收紧。

示例（仅写法示例，不是任意视频事实）：

> 女方越肩拍男方近景。男方先向画面左边撇头，停住，再转回来对着女方说“对，我活该，我活该”。重复时肩膀前压，前臂向桌面方向下落。女方后脑和肩留在右前景。以切镜进入，不用推进代替切镜。

有依据的声线和语气才进入忠实版；未听辨的声音导演建议另列。重要约束是身份/位置、动作顺序、对白变化、视线/物件、切镜。自然呼吸眨眼保持连续，确认的特殊闭眼才指定。

原片复刻保留台词、镜头、节奏；换故事先提取因果链（受指责→避视→回头→重复反驳→动作加重→收住），对齐新对白后重新计时。不能机械复用旧时间戳让对白说不完。

多段按完整句/自然停顿和已确认平台时长切，一段可有多个镜头。段尾保存姿势、视线、道具和声音衔接；分清局部时间与原片绝对区间。平台时长未知时不宣称 Seedance 2.5 必须/最多几秒。

生成后分别对照人物空间、镜头、动作次数/先后、表情视线、台词语气、动作重音同步，引用原片/新片时间。别用“相似度95%”代替证据。每次先改主要偏差对应的约束。
