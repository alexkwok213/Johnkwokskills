# Seedance 2.5：直接生成提示词

核对日期：2026-10-15。以下来自火山引擎的官方指南，模型或接口变更时重新核对，不用第三方教程代替官方规范。

- [官方模型教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)
- [官方创建视频任务API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

## 写作规则

1. 先明确素材职责（仅在有真实素材时），用一句话写主体、地点、事件和风格，再按时间轴/镜头写情节，末尾补贯穿全片的连续性与声音。
2. **默认写顺序，不写逐段秒数。** 官方指南支持“镜头顺序/时间轴”两种写法；2.5支持时间戳不代表每条提示词必须加秒。单镜头用第一阶段/第二阶段/最后，多个真实镜头用镜头一/镜头二。只有用户要卡点等精确时序时才加整数秒；源视频的小数秒留在报告，不冒充模型逐帧控制。
3. 动作以概括连续过程为主，关键接触/视线/表情细写，避免重复堆同一动作。表情写脸部变化，少用只有情绪标签的成语。画面优先正向约束，音频和字幕可以明确负向控制。
4. 素材按实际上传顺序用 `@图片1`、`@视频1`、`@音频1` 指代，并说明分别提供外貌、动作、场景、音色等。无参考素材时输出独立的文字生成稿，不带需要用户填的引用。
5. 模仿动作的新生成任务写“动作和节奏参考@视频1”，不要无意写成“编辑视频/修改/替换”等编辑任务指令。实际编辑任务依用户目的采用相应输入、宽高比与时长规则，不能混用纯生成参数。
6. 无对白时不创造台词。静音参考可以要求“不要任何声音”；有对白时按官方教程可用 `{台词}`，音效用 `<音效>`，音乐用 `(音乐)`，字幕用 `〖字幕〗`。不生成字幕时直接写“不要字幕”。

## 本用户的交付要求

先按 [input-modes.md](input-modes.md) 确认首帧或全能参考。仅首帧时以图中人物、产品、服装、场景和构图起步，重点描述动作与自然变化；图中已明确的外貌不重造。全能参考先明确 `@图片1` 用于开场/人物，其他实际素材分别锁产品、镜头或动作；不把所有素材都定义成完整外观来源。

首帧模式与全模态模式为互斥接口场景，全参考中“图片1作为开场”是文字参考，不等同于first_frame严格锁定；具体取舍见官方API和输入方式说明。

先在回复中给一整块中文生成正文，让用户直接复制；参数建议和参考素材说明放正文外。保存 `prompt.txt`，再附可选报告。示例：[仅首帧](examples/food-prompt.txt)、[全能参考](examples/food-seedance25-omni.txt)。写法符合规范不等于已验证生成效果。
