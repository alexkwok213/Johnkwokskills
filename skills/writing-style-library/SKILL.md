# 写作风格库

## 查阅收藏

- [大欢](references/dahuan.md)｜个人写作风格。中文公众号的商业观察、案例速递和观点拆解。
- [半佛仙人](references/banfo-xianren.md)｜创作者参照。商业观察、利益关系和避坑写法。

用户指定作者时，读取对应条目。用户想比较风格时，按适用文体、叙事视角、段落推进和具体手法比较。用户明确要求用某种写法改稿时，再把选中的手法应用到稿件里。

## 收藏新风格

收到收藏请求时，在 `references/` 为该风格维护一份独立的 Markdown 文件，并更新本页索引。已有条目时补充原文件。记录适用文体、可观察的写作手法和来源链接。有原作时，用具体段落说明手法。来源只有访谈、第三方分析或少量样本时，写清材料范围。只收到作者名时先记为待补资料，等有样本再归纳。引用保留署名和链接，摘录限于说明手法所需的短句。
